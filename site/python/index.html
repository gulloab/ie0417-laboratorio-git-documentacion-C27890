Documentación de scrapy

Scrapy es un framework de Python para extraer datos de sitios web de forma escalable y asíncrona. Está pensado para automatizar el rastreo de sitios completos y la extracción estructurada de su contenido.

El flujo central del framework conecta varias piezas: el usuario define una Spider que genera objetos Request; el motor los despacha a través de una cadena de downloadermiddlewares antes de obtener un Response; ese response se procesa con el módulo selector para extraer datos, que luego pasan por pipelines para su almacenamiento final.

Esta documentación cubre la referencia de API generada a partir de los docstrings del paquete, enfocada en los módulos que un desarrollador nuevo tocaría primero: spiders, http y selector.
